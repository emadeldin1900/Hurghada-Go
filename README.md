# Hurghada Go

Travel recommendations & trip itinerary platform for Hurghada & the Red Sea.

## Tech Stack

- **React 19**
- **Vite**
- **Tailwind CSS v4**
- **Lucide Icons**

## Getting Started

Install dependencies:
```bash
npm install
```

Start development server:
```bash
npm run dev
```

Build for production:
```bash
npm run build
```
